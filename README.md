# NPC · 사건 생성 확장 (v0.2.2)

`npc-event-director` 폴더를 SillyTavern의 `data/<사용자>/extensions/third-party/`에 복사한 뒤 새로고침하세요. 채팅 입력창의 **마법봉 메뉴 → NPC · 사건 생성**에서 관리 창을 엽니다. **설정** 탭에 Jev API key와 model(기본 `jev-latest`)을 입력합니다. 메인 RP 생성은 현재 SillyTavern 연결을 그대로 사용하므로 별도 LLM 연결 프로필과 임베딩 키가 필요하지 않습니다.

## 동작

- 일반 탭: NPC 개입, 사건, NPC 자율행동, 감정 과잉 억제.
- 부정 탭: 싸움 유지, 빌런, 부정 세계, 부정 압력.
- 설정 탭: Jev key/model, 최근 메시지 수, **한국어 번역 전용 연결 프로필**. 일반·부정 탭 각각의 **생성 후 실제 주입 내용 확인**을 켜면 생성 중 등록된 지시의 원문과 한국어 번역을 팝업으로 표시합니다. 번역은 선택한 SillyTavern 연결 프로필을 사용하며 RP 연결에는 영향을 주지 않습니다. 번역 오류 시 원문을 계속 볼 수 있습니다.
- `OFF`는 중지, `AUTO`는 주사위 기회와 Jev 판정에 따름, `ON`은 매 턴 검토합니다. `ON`도 Jev의 맥락 veto를 우회하지 않습니다. 감정/부정 세계 같은 지속 보정은 활성화된 턴마다 적용합니다.
- 최근 채팅 기본 10개를 Jev에 보냅니다. 주사위 기회가 없고 진행 중 빌런이나 ON 기능이 없으면 Jev를 호출하지 않습니다. 한 번 호출할 때 짧은 판정들을 함께 보냅니다.
- Jev가 허용한 경우만 짧은 지시를 `In-chat depth 0 / system`으로 주입합니다. 응답 후 제거합니다.
- NPC가 실제로 관여하는 턴에만 `NPC_CONTINUITY`와 `NPC_CRAFT_PASS`의 짧은 확장용 조각을 넣습니다. 기존 프리셋의 `NPC_PHILOSOPHY`는 중복하지 않습니다.
- 빌런 프로필의 access, leverage, motive, method, competence, composure는 시작 시 한 번 뽑아 채팅 상태에 유지합니다. 부정 탭의 **빌런 이벤트 종료**로 초기화합니다. 싸움 유지 ON 중에는 빌런 진행과 추첨이 일시정지됩니다.
- 부정 세계의 1% 동정 예외는 그 응답에서 자연스럽게 새로 등장하는 비시트 NPC 한 명에게만 적용됩니다.
- **원작 세계관 반영**은 부정 세계와 독립적인 설정입니다(기본 AUTO). NPC·사건 개입이 선택된 턴에만 제공된 캐릭터 카드, 로어, 채팅에 근거한 원작 지시를 더합니다. 기존 프리셋의 세계관 지시와 중복을 줄입니다.
- 설정 탭은 현재 채팅의 `GENRE` 변수 값을 보여줍니다. Jev 판정에도 이 값만 전달합니다. 실제 활성화된 장르 프롬프트 전체가 변수에 들어 있지 않다면 확장이 그 전문을 읽는 것은 아닙니다.
- OOC 입력 `(ooc:`은 그 생성의 모든 주입과 추첨을 건너뜁니다.

설정과 각 채팅 상태는 SillyTavern 확장 설정에 저장됩니다. 기존 빠답 변수는 자동으로 가져오지 않습니다. 기존 빠답 자동 실행을 끄고 이 확장을 사용하세요. 둘을 함께 켜면 지시가 중복됩니다.

`director.js`의 `retrievalContext(provider, messages)`는 나중에 optional retrieval provider를 붙일 자리입니다. v0.1은 provider를 등록하지 않으며, Jev에는 최근 채팅만 전달합니다.

Jev 호출은 브라우저에서 TypeSafe API로 직접 갑니다. 키는 SillyTavern 확장 설정에 저장됩니다. 브라우저의 교차 출처 정책으로 요청이 막히는 배포 환경에서는 별도 서버 프록시가 필요합니다. 이 버전은 실제 SillyTavern 설치 환경에서의 통합 검증 전 단계입니다.
